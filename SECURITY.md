# Security

## Reporting a vulnerability

Do not open a public issue for a suspected security vulnerability.

Use GitHub private vulnerability reporting or a private GitHub Security Advisory for this repository when available.

Include:

- affected version or commit;
- reproduction steps;
- expected and observed behavior;
- impact;
- any proposed fix or mitigation.

## Supported versions

Security fixes are applied to the latest release and the `main` branch. Older releases may not receive backports.
